# Documentação / Documentation

Documentos atuais têm leitura em português e inglês. Os protocolos e relatórios científicos originais são evidência congelada; traduções ficam em arquivos separados, preservando os bytes originais, IDs e datas. Registros históricos descrevem o estado de sua época, não substituem o estado atual.

Current documentation is available in Portuguese and English. Original scientific protocols/reports are frozen evidence; translations live separately, preserving original bytes, IDs and dates. Historical records describe their own period rather than replacing current status.
