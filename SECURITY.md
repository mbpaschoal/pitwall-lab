# Security policy / Política de segurança

## Report privately / Relate em privado

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/mbpaschoal/pitwall-lab/security/advisories/new). Include affected version, impact and a minimal reproduction. Do not publish credentials, exploit details or personal data in public issues. Never test against other users or disrupt the public service.

Relate suspeitas pelo [canal privado do GitHub](https://github.com/mbpaschoal/pitwall-lab/security/advisories/new). Informe versão, impacto e reprodução mínima. Não publique credenciais, detalhes de exploração ou dados pessoais em issues públicas. Não teste contra outros usuários nem interrompa o serviço público.

## Supported scope / Escopo mantido

Security fixes target the current dashboard release, its presentation dependencies and GitHub workflows. Original scientific artifacts and model v1 remain preserved evidence; auditing them does not authorize retraining or replacing registered forecasts. Historical portable packages retain the dependencies of their release: use the current package for serving an app.

Correções se destinam à versão atual do dashboard, às dependências de apresentação e aos workflows. Artefatos científicos e modelo v1 permanecem evidências preservadas; sua auditoria não autoriza treino nem substituição de previsões registradas. Pacotes portáteis históricos conservam as dependências da época: use o pacote atual para hospedar o aplicativo.

## Maintenance / Manutenção

This is an individually maintained educational project; there is no guaranteed response time. See [security controls and limits in English](docs/en/SECURITY.md) or [em português](docs/SEGURANCA.md). A passing scan is not proof that a system has no vulnerabilities.

Projeto educacional mantido individualmente, sem prazo de resposta garantido. Consulte os controles e limites acima. Uma verificação aprovada não comprova ausência de vulnerabilidades.
