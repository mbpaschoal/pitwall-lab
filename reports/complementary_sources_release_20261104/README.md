# Fontes complementares — preparação da publicação 0.9.2

Created by: MBPaschoal

Status: prepared for publication

Type: release report

English: [README.en.md](README.en.md)

A entrega local foi conciliada com o main 0.8.31 (`1c031c1231408eae8410bf6783b94555f4bcc9c0`), sem alterar suas correções de toque, navegação e segurança. A [validação local](local-validation.json) registra 93 testes focais, 17 suítes/146 testes portáteis e 483 arquivos conferidos contra o ZIP. Os 282 arquivos científicos/de previsões monitorados permanecem intactos.

O leitor conserva a base e os hashes de idade dos pneus: aplica as 262 revisões auditadas antes do complemento de fontes aprovado, em memória. A revisão de todos os valores anteriormente exibidos não encontrou mudança esportiva. Os três Q2 de São Paulo 2024 recebem procedência, com candidatos separados; contexto Pirelli não é sessão observada. [Contrato e reprodução PT/EN](../../docs/FONTES_COMPLEMENTARES.md).

As versões locais 0.9.0/0.9.1 e suas tentativas permanecem no arquivo de autoria. Esta publicação seleciona código, complemento aprovado e documentação; não inclui seus arquivos brutos, HTML integral ou cofre. Os testes públicos verificam o bundle real aprovado, sua composição com a revisão anterior e fixtures controladas do construtor. A validação dos recibos brutos foi feita localmente e não é atribuída ao CI público. Captura recente não comprova disponibilidade histórica, nem ganho preditivo.

Este registro descreve a preparação local. CI, merge, release e comportamento do host público exigem evidências próprias; resultados posteriores devem citar os IDs/URLs concretos sem converter teste local em prova de deploy.
